Fix torch._classes RuntimeError and PDF upload functionality

- Disabled Streamlit file watcher via STREAMLIT_SERVER_FILE_WATCHER_TYPE environment variable
- Applied early torch._classes monkeypatch before Streamlit imports to prevent watcher introspection errors
- Created SafeClassesProxy that properly handles __path__._path attribute access
- Fixed PDF text extraction: added file pointer reset, proper error handling, and empty text detection
- Improved file upload validation: check for uploaded file existence and handle empty PDFs gracefully
- Added warning messages for failed PDF extraction (image-based or corrupted PDFs)
- Removed duplicate patching code from load_model() function
- Added comprehensive plotting explanation documentation

This fix resolves:
1. RuntimeError that occurred when Streamlit's file watcher tried to introspect torch._classes.__path__._path
2. PDF upload issues where text extraction failed silently, causing "Please enter a medical report" error
